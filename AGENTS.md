# Работа с публичным репозиторием

- Перед изменениями прочитайте `README.md`, концепцию проекта и относящуюся к задаче документацию.
- Проект находится на стадии Product / Architecture Draft. Не представляйте планы как реализованные функции; реализацию продукта начинайте после согласования архитектурного плана.
- Документация и названия её файлов — на русском; технические идентификаторы — на английском. Для будущего UI предусматривать русский и английский.
- Вносите минимальные изменения по задаче и проверяйте результат.
- Перед публикацией проверяйте состав файлов и отсутствие секретов, персональных данных, внутренних адресов и конфигураций реальных окружений.
- Публикация общих знаний требует утверждения; новая версия не должна автоматически изменять проекты-потребители.
- Не выбирайте и не меняйте лицензию без решения владельца.
