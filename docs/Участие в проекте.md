# Участие в Developer OS

Проект находится на стадии Product / Architecture Draft. Начните с [концепции проекта](../Концепция%20проекта.md) и [принципа фиксации знаний](Фиксация%20знаний.md).

## Предложить идею

Создайте issue на [GitVerse](https://gitverse.ru/alexey.marochkin/devos) или [GitHub](https://github.com/alexey-marochkin/devos). Опишите проблему, рабочий сценарий, ожидаемый результат и ограничения. Перед созданием проверьте существующие обсуждения на обеих площадках; дублировать одно предложение не требуется.

## Подготовить изменение

1. Для существенных изменений сначала согласуйте задачу в issue.
2. Создайте отдельную ветку и внесите минимальное изменение по задаче.
3. Проверьте ссылки, формулировки и отображение затронутых материалов. Для лендинга проверьте также узкий экран и клавиатурную навигацию.
4. Откройте pull request с описанием проблемы, результата и выполненных проверок. Укажите связанные обсуждения на другой площадке, если они есть.

Документация и названия её файлов — на русском языке; служебные имена `README.md` и `AGENTS.md` сохраняются. Технические идентификаторы — на английском. Будущий UI должен предусматривать русский и английский языки.

Не выдавайте roadmap за реализованное поведение. Публикация общих знаний требует проверки и утверждения; новая версия компонента не означает автоматического применения в проектах.

Не добавляйте секреты, персональные данные, внутренние адреса, конфигурации реальных окружений и приватные эксплуатационные документы. Для примеров используйте обезличенные данные. Права на сторонние материалы должны быть понятны до включения.

Лицензия проекта ещё не выбрана. До её согласования не добавляйте сторонние материалы, требующие несовместимых разрешений, и не обещайте права от имени владельца.
