# Developer OS

Персональная инженерная среда, которая связывает знания, задачи, Git, AI-агентов, проверки и инфраструктуру. Цель — согласовать привычные инструменты разработчика и сохранять инженерный опыт между проектами.

**Статус: Product / Architecture Draft.** Сейчас опубликованы концепция, архитектурные принципы и макет лендинга. Описанные интеграции и roadmap — планируемые возможности; готового продукта и инструкции установки пока нет.

## Обсуждение и вклад

Репозитории проекта — [GitVerse](https://gitverse.ru/alexey.marochkin/devos) и [GitHub](https://github.com/alexey-marochkin/devos). Публичный набор предназначен для обеих площадок; автоматическая синхронизация не настроена.

Можно предложить пользовательский сценарий, обсудить архитектуру, уточнить документацию или подготовить изменение через issue и pull request. Реализация продукта начинается после согласования архитектурного плана.

Лицензия пока не выбрана. Публичная доступность репозитория сама по себе не предоставляет лицензионных разрешений на использование материалов.
